# 扩建小岛与雏菊的日常

本轮基于 `island_dusk_living.blend` 的可编辑物件制作，旧版源文件和网页模型保留。只使用本地 Blender 5.2.1，没有调用 Tripo 或生成新的角色。

## 空间

地形平面沿 X 放大 1.28 倍、Y 放大 1.38 倍，地表投影面积为旧版的 1.7664 倍。建筑、人物、独立树木的尺寸保留，建筑附属花盆和窗藤整体平移；河道、桥面、菜园围栏和地表一起扩展。

新增四棵带果实的小树、两处有实心屋顶的避雨处、花园工作台、雨水桶、果筐、花箱、长椅及连接步道。保留住宅—菜田—石桥—咖啡馆的布局关系，并留出草地。七个生活地点是廊下、菜园、院边花草、果树林、咖啡馆檐下、溪边长椅和工作台。

0.3 米网格采样得到当前可走区域约为旧版的 2.09 倍；这与地表面积增幅不同，因为建筑等固定障碍没有同步变大。导航仍为高度函数和二维碰撞范围，尚非完整物理或任意网格寻路。

## 使用

- 打开 `http://127.0.0.1:8765/viewer/`，默认观景时雏菊自动生活。
- 「看看她」跟随人物，再点「回到全岛」恢复之前的观察镜头。
- 「进入小岛」从当前位置接管，取消自主路线和动作；退出后从当前地点重新安排日程。
- 日记新增「去果树林」「去溪边」。窄屏下日记可展开和收起，选目的地后自动收起。
- 改变时刻会切换日程，选择小雨会让她走到最近可达的雨棚。角色始终步行到目的地，不会传送。

## 日程与边界

| 时段 | 活动安排 |
| --- | --- |
| 06–10 点 | 看菜苗、整理工作台、照料花草、逛果园 |
| 10–16 点 | 果园、咖啡馆、花草、菜园、溪边依次停留 |
| 16–20 点 | 溪边、咖啡馆、花草、小院 |
| 20–22 点 | 小院与院边花草 |
| 22–06 点 | 回廊下休息并停留 |
| 小雨 | 优先寻找可达雨棚，雨停后恢复当前时段日程 |

活动使用现有 Idle / Walk / Plant / Water / Harvest 骨骼片段。果园的摘取手势和菜园浇水属于观景生活演出，不变更作物、物品、金币或订单。长椅旁目前是站立歇脚，没有坐姿、饮茶或室内睡眠动作。下一轮可继续精修这些动作与物件接触。

暂停风景、打开对话框、切到后台时，自主行动冻结；暂停世界时间只固定日程时段，人物仍会活动。关闭页面后没有离线自主行动。保存的是当前位置，重新打开后根据当前时段和天气重新安排路线。

沿用原游戏存档键和三块菜田 ID，旧版位置坐标仅迁移一次；物品、金币、作物计时和订单不清空。世界时钟仍使用独立存档。

## 文件与验证

- `island_expanded.blend`：保留独立物件的可编辑场景。
- `island_expanded.glb`：490,128 三角面，20,859,068 字节，静态场景合批，动态物体单独保留。
- `scene.json`：地形比例、碰撞范围、可活动地点、遮雨范围和场景节点。
- `../../viewer/resident.mjs`：无经济状态副作用的日程与导航控制器。
- `../../scripts/expand_island.py`：固定种子的本地生成脚本。
- `../../scripts/test_resident.mjs`：扩岛、路径、日程、天气、接管、存档迁移测试。

```sh
/Applications/Blender.app/Contents/MacOS/Blender -b --python scripts/expand_island.py
node scripts/test_resident.mjs
node scripts/test_living.mjs
node scripts/test_world.mjs
# 需要 gltf-validator，或者通过 GLTF_VALIDATOR_MODULE 指定其路径
node scripts/validate_expansion.cjs
```

本轮完成扩岛布局与自主生活基础。主岛细节仍待进一步校准，远景岛仍不能前往。
