# 云上时光 · 昼夜、天气与远景群岛

打开 [小岛](http://127.0.0.1:8765/viewer/)，点击右上角时钟展开控制面板。

## 使用

- 初次进入为 10:00 晴天，30 分钟现实时间走过一天；支持 0.5、1、4 倍流速。
- 清晨 06:30、正午 12:00、黄昏 18:00、夜晚 22:00；选择预设或拖动时间滑块会暂停时间，便于观察。点击「继续时间」恢复。
- 天气独立选择晴天、多云、薄雾和小雨，约数秒内平滑变化。云量、远景雾、风、光照、雨丝与地面粗糙度随天气变化。
- 时间仅在页面可见且风景未暂停时推进。「暂停时间」不停止河流、云朵和角色；「暂停风景」一起暂停。系统减少动态效果沿用原页面规则。
- 世界偏好保存于 `island-world-v1`，包含日期、时刻、流速、播放与天气；关闭页面后不追赶离线昼夜。种植使用自己的真实时间与原存档，互不改写。
- 「流畅画面」减少云层实例、雨滴数量、远岛数量和阴影分辨率。

## 构成

太阳和月光方向连续更新，太阳光强与月光强度在晨昏交接，避免单个光源瞬间跳到另一侧。天空、云朵、环境光、雾和水面照明使用同一时间。夜间点亮原有发光材质、补充建筑和路径的暖光，并显示星空与萤火虫。

12 座远岛采用真实三维几何，带森林、房屋、遗迹和瀑布，环绕主岛布置。主场景沿用正交镜头，因此远岛额外缩小并根据距离与屏幕天空色混入雾色。云海使用实例化的透明积云面片，有慢速漂移和三维遮挡关系；天空还包含程序云和星点。

雨丝使用动态几何，房屋范围内的下落下限抬到屋顶，地面与水面以下的雨丝截断；这是外景近似，不是完整天气物理。当前天气手动选择，尚没有自动天气预报、雨水浇灌作物、人物撑伞、雷电或四季。远岛作为背景，尚不可传送或登陆。

## 文件

| 文件 | 用途 |
| --- | --- |
| `distant_islands.blend` | 本机 Blender 5.2.1 制作的可编辑群岛；每座岛单独对象 |
| `distant_islands.glb` | 12 岛，35,760 三角面，781,560 字节；不含碰撞或玩家逻辑 |
| `cloud_bank.png` | 1536×1024 RGBA 中性积云纹理，保留生成的透明度 |
| `../../viewer/world.js` | 天空、远岛、云海、雨、灯光、材质与界面联动 |
| `../../viewer/world-state.mjs` | 可独立测试的昼夜时钟、天气过渡与偏好恢复 |
| `../../scripts/build_world_islands.py` | 固定随机种子 9182026 的本地群岛生成脚本 |
| `../../reference/world/daylight_islands.png` | 用户提供的白天群岛视觉参考 |
| `../../reference/world/cloud_prompt.txt` | 积云生成完整提示词与工具记录 |

积云使用内置 image_gen 工具生成；群岛全部本地制作，本轮没有消耗 Tripo 积分。原黄昏背景与既有 Blender 主岛文件保留，新的动态天空在网页实时运行。

## 重现与验证

在项目根目录：

```sh
/Applications/Blender.app/Contents/MacOS/Blender -b --python scripts/build_world_islands.py
node scripts/test_world.mjs
node scripts/test_living.mjs
```

时钟与天气 5 项测试、原游戏循环 4 项测试通过；远岛 GLB 校验 0 错误、0 警告。实测与当前限制见 `reports/world_acceptance.md`。
