# 悬浮小岛 · 建模需求文档（黄昏版）

> 用途：本文档基于参考效果图（黄昏光照的半写实治愈风悬浮岛），指导 AI 使用 Blender 完成**纯场景建模**，不涉及游戏玩法与交互逻辑。
> 工作方式：**先统一规格 → 逐件建模 → 整岛拼装**，请严格按第 4 章的物件清单逐个建模，每件完成后渲染预览确认再进入下一件。

---

## 1. 总体目标

- 还原参考图的场景内容：一座悬浮空岛，含主角小屋、农田区、溪流瀑布、石桥、咖啡馆露台、丰富植被与黄昏云海氛围
- 交付可在 Three.js / 网页端查看的 3D 场景（glTF/.glb），**本期只做静态场景，不做角色动画、不做交互**
- 风格定位：**风格化半写实（stylized semi-realistic）**——保留参考图的光影氛围与材质倾向，但主动简化几何细节，避免按插画精度死磕

## 2. 重要：对参考图的修正与取舍

参考图为 AI 生成图，存在物理逻辑错误，建模时必须修正：

1. 右侧石桥/木桥的连接关系要合理：桥两端必须落在实地，溪流从桥下穿过
2. 原图悬空漂浮的灯笼改为：挂在路灯杆、屋檐、树枝或拉绳上，必须有支撑结构
3. 右下角悬挂小船改为可选装饰（见物件 D12），滑轮与绳索结构要成立
4. 所有台阶两端必须连通，不得"通向空气"
5. 植被密度按参考图的 **50%** 执行（插画密度在 3D 中不可行，靠重点位置点缀出氛围即可）

## 3. 统一规格（所有物件建模前必须遵守）

### 3.1 比例尺
- 统一单位：1 单位 = 1 米
- 主角小人（仅做比例参照物，可后做）：高 1.4 单位
- 单层建筑层高：2.8~3.2 单位；门板高 2.0 单位

### 3.2 交付规范
- 每个物件交付独立 .glb，另保留 .blend 源文件
- 原点统一在物件**底部中心**，正面朝 -Y（拼装时统一约定）
- 命名使用清单中的英文 ID，全小写下划线
- 材质：PBR 基础材质（BaseColor + Roughness），可用小尺寸手绘/程序纹理，单物件贴图 ≤ 1024px
- 面数预算：见各物件条目；全场景目标 ≤ 60 万三角面（本期静态展示可放宽，但植被必须用面片插片技巧控制）

### 3.3 统一色板与光照（拼装场景时执行）
- 天空：地平线粉橙 `#F5C8A8` → 头顶淡紫 `#C8B0E0`，太阳低角度位于画面右上方
- 主光：暖橙平行光 `#FFD9A0`，低角度（约 15° 仰角），长阴影
- 补光：淡紫环境光 `#B8A8D8`；建筑窗内、灯笼、路灯使用暖黄自发光 `#FFDF9E`
- 草地绿 `#8FBF6A`，岩石暖灰 `#B8A898`，水体浅青蓝 `#7ECDE0`，屋顶青灰绿 `#6A9E8F`
- 云海：岛周与下方填充蓬松低模云，淡粉紫调

### E. 水体（拼装阶段制作，不用单独建模）

- `stream_surface`：溪流面片，沿 A1 河道铺设；`waterfall_sheet`：岛缘瀑布面片 ×1~2，半透明浅青蓝 + 白色泡沫边缘；本期静态场景接受静态水面，流动效果留待后续

### F. 比例参照（最后做或先拿胶囊体占位）

- `player_ref`：1.4 单位高的 Q 版小人剪影（无需细节），仅用于校验各物件比例，正式角色后续单独做

## 5. 拼装要求（所有单件验收后进行）

1. 按参考图布局拼装：左上小屋区（B1 + D2 + D10）→ 左中农田区（C 组）→ 中部溪流河道 + 石桥（B3）→ 右侧咖啡馆露台（B2，露台朝岛缘挑出）→ 各区以石板小径（D6）串联
2. 植被分布：花丛（D3）沿小径两侧与建筑墙根成簇点缀；垂藤（D4）集中在岛缘瀑布两侧与咖啡馆露台下方；大树（D1）全岛 5~7 棵，避免均匀分布
3. 云海（D11）：岛体中下部环绕 6~10 朵，下方远处再散布 3~5 朵；远景小岛（A2）放在右后、左后各一
4. 按第 3.3 节设置黄昏光照与天空，开启软阴影
5. 验收镜头：按参考图同角度（斜俯视约 30°，从南向北看）出一张 2048×1152 渲染图，与参考图对比验收

## 6. 验收标准

- [ ] 所有物件独立成件、命名规范、原点朝向统一
- [ ] 修正了参考图的全部逻辑错误（桥、灯笼、台阶）
- [ ] 整场景面数 ≤ 60 万，合并导出单个 .glb ≤ 25MB
- [ ] 验收渲染图的构图、光照氛围与参考图神似（允许植被密度明显更低）
- [ ] 场景在 Three.js 查看器中可流畅旋转缩放查看（桌面 60fps）

## 7. 执行顺序建议

1. 先建 A1 岛体 + F 比例小人 → 确认全局比例
2. 建 B1 小屋 → 确认风格与材质方向（这是全场最重的单件）
3. 依次完成 B2、B3、C 组
4. 建 D 组装饰单元（每类 1 个即可，拼装时复制）
5. 拼装 + 水体 + 光照 + 出验收图
